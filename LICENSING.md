This project uses two licences so that code stays easy to reuse and written guidance always credits its source.

| What | Paths | Licence |
|---|---|---|
| Code | `scripts/`, `mcp/`, `registry/`, `evals/*.py`, `action.yml`, `.github/`, `tests/` | [MIT](LICENSE) |
| Written content | `SKILL.md`, `references/`, `templates/`, `packs/`, `i18n/`, `adapters/`, `docs/`, `evals/cases/` | [CC BY 4.0](LICENSE-CONTENT) |

If a file isn't listed, code files are MIT and prose files are CC BY 4.0.

Using the content in your own product, course or client work is welcome. Credit "Venus One (Pty) Ltd and contributors" with a link to the repository and say if you changed it.
